Metal Gear Solid Encyclopedia

WDD 131 Website Planning Document

Site Name

Metal Gear Solid Encyclopedia

I chose this name because it clearly represents an online encyclopedia dedicated to the Metal Gear Solid series, providing information about its games, characters, and story.

Site Purpose

This website will provide information about the Metal Gear Solid franchise, including the games, timeline, main characters, image gallery, and a contact page. Visitors will also be able to filter games and save favorites using JavaScript and localStorage.

Scenarios

  • Which Metal Gear Solid game should I play first?
  • Who is Big Boss and why is he important to the story?

Color Schema
